## Saqlangan narsalar

`.git` ichidagi barcha fayllar ZIPdagi asl nusxadan baytma-bayt saqlandi (tarix, branch, remote, index). Commit/push yoki hosting o‘zgarishi qilinmadi. `package.json` va `package-lock.json` ham yuborgan nusxangiz bilan aynan bir xil; ulardagi avvalgi o‘zgarishlar bekor qilinmagan.

Asl yuklamadagi `.env` o‘zgartirilmagan, lekin maxfiy kalitlarni qayta tarqatmaslik uchun qaytariladigan ZIPga kiritilmagan. Kompyuteringizdagi `.env` va Render Environment qiymatlarini saqlang. `.env.example` faqat namuna. `node_modules`, `dist` va build cache qayta yig‘iladi.

## Deploy

1. ZIPni yangi papkaga oching yoki o‘zgarishlarni mavjud backend repoga ko‘chiring. Mavjud lokal `.env` va `.git`ni o‘chirib yubormang.
2. `git status` / `git diff` bilan ko‘rib chiqing. Commit va pushni o‘zingiz bajarasiz; maxfiy `.env`ni Gitga qo‘shmang.
3. Renderda mavjud Node 22.x va Environment qiymatlarini saqlang. Odatdagi build: `npm ci && npm run prisma:generate && npm run build`.
4. Backend bilan birga yangilangan frontendni ham deploy qiling. Yangi DB migration qo‘shilmadi; mavjud start/deploy jarayoni saqlandi.
5. Ovoz uchun mavjud backend `OPENAI_API_KEY` ishlatiladi; frontendga kalit qo‘ymang. API hisobidagi balans/model ruxsati va platforma ovoz limiti zarur. Bildirishnoma signali uchun tashqi servis yoki kalit kerak emas.
